# swiggy-excel-dashboard
> Interactive Excel dashboard project based on Swiggy food delivery data, designed to analyze sales performance, customer behavior, restaurant trends, and order patterns. Built using pivot tables, charts, slicers, conditional formatting, and KPI tracking to generate meaningful business insights through data visualization.
# Swiggy Dashboard Analysis

An interactive Excel dashboard built to analyze Swiggy food delivery data and customer trends.

## Features
- Total sales and revenue tracking
- Order trend analysis
- Top restaurants and cuisines
- Customer insights
- KPI monitoring
- Interactive slicers and filters

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## Project Objective
To derive business insights from Swiggy order data and present them through an interactive dashboard.
